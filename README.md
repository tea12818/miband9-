# 小米手环 9（NFC 版）终端表盘 · 设计与可导入素材包

一个把整块屏幕伪装成 Linux/BSD 终端的表盘：顶部 shell 提示符、大号等宽时间、`resmon` 资源面板、
`tail -f` 日志窗、底部闪烁光标。全部素材已生成，192×490 逐像素对齐，可直接导入第三方表盘编辑器或当相册表盘底图。

> 适用机型：小米手环 9 / 9 NFC。两者屏幕完全一致（1.62″ AMOLED，192×490，胶囊形），
> 表盘资源互通；NFC 版只多门禁卡与公交卡功能，不影响表盘逻辑。同一套素材两版通吃。

---

## 1. 设计规范

### 1.1 画布与安全区

| 项 | 值 |
|---|---|
| 画布 | 192 × 490（严格 1:1，勿缩放） |
| 面板 | AMOLED，纯黑不发光的像素不耗电 |
| 底色 | `#040705`（近黑微绿；想要极限省电换 `#000000`） |
| 安全边距 | 四周 10px。文字最右 182、最下 472，圆角区域不放关键信息 |
| 内容栅格 | 等宽字符步进：16px→10px、18px→11px、20px→12px、53px→32px |
| 竖排栅格 | 25px 行距（指标区）、18px 行距（日志区） |

### 1.2 调色板（5 档亮度，模拟单色 CRT 磷光）

| 语义 | HEX | 用途 |
|---|---|---|
| G0 高亮 | `#E2FFEC` | 只给大号时间，全屏唯一"白" |
| G1 主绿 | `#36FF74` | 数值、光标行、当前状态 |
| G2 中绿 | `#1E9648` | 标签、命令、日期 |
| G3 暗绿 | `#105228` | 分隔线、未填充段、注释、次要日志 |
| CY 青 | `#40E8D6` | 光标、温度、功率（唯一冷色点缀） |
| AM 琥珀 | `#FFB000` | 低电模式整体换色 |
| RED 红 | `#FF5454` | 警告 / 心率超限 |

> 只用两色相（绿 + 青），不引入蓝紫；琥珀/红只在异常态出现，一出现就是"报警"，语义不混。

### 1.3 字体

* 等宽：**DejaVu Sans Mono**（无版权顾虑，字形接近 Terminus / IBM VGA 的现代版）。
  次选 `Consolas` / `Liberation Mono`。禁止用比例字体，否则右侧数字列会参差。
* 大号时间：DejaVu Sans Mono **Bold 53px**，步进 32px，`HH:MM` 五字共 160px，居中起点 x=16。
* 中文（仅通知卡）：SimHei / 思源黑体，26px / 22px。

### 1.4 六个状态

| 文件 | 状态 | 说明 |
|---|---|---|
| `out/preview_idle.png` | 主态 | 常规待机，绿色系 |
| `out/preview_notify.png` | 通知 | 下半屏压黑 + 终端风通知卡，含中文字幕与三键位提示 |
| `out/preview_sport.png` | 运动 | 命令变 `$ run`，面板换 PACE/HR/CAD/KCAL/PWR，心率红色 |
| `out/preview_lowbat.png` | 低电 | 全场转琥珀，电量条单格红色，日志出现 `warn bat9%` |
| `out/preview_boot.png` | 开机 | `$ boot` + `[ OK ]` 引导日志，时间压暗 |
| `out/preview_aod.png` | 息屏 AOD | 纯黑 + 28% 亮度时间 + 4 格电量点 + 光标，带像素位移防残影 |
| `out/preview_album.png` | 相册版底图 | 大号时间行留白，给系统相册表盘叠自己的时间 |
| `out/preview_all.png` | 六态联排 | 交付总览 |

### 1.5 防烧屏 / 省电（AMOLED 手环的真实约束）

1. **大面积纯黑**：全屏只有约 18% 像素亮。这是本设计最大的省电来源，也是终端风天然优势。
2. **静态像素别常亮**：分隔线、提示符如果用 G1 全亮，长期会在屏上留影。已统一降到 G3。
3. **秒数只留一处**：`cmd.sec` 是唯一的每秒变化元素。想再省电就把它删掉（表盘从"每秒重绘"降到"每分钟"）。
   心率波形、日志行按事件刷新，不要接秒级数据源。
4. **AOD 位移**：`layout.json → aod.shake.offsets = [0,2,4,2]`，每小时整块内容循环下移 1px 级，
   避免同一行数字长期点亮同一批像素。
5. AOD 亮度取 G1 的 28%（`#2C6840`）；若系统不支持自定义 AOD，主表盘降亮后依然可读（因为主体是暗色底 + 亮字）。

## 2. 素材清单

```
out/
├─ preview_idle.png            主态 192×490（可直出当表盘图）
├─ preview_idle_x3.png         3 倍最近邻放大，校对像素用

├─ preview_all.png / _x2.png   六态联排
├─ assets/
│  ├─ base.png                 底板：所有动态值留空（相册表盘 / 编辑器背景层直接用这张）
│  ├─ big/                     0-9 : . -  53px Bold，单字 PNG，宽 32
│  ├─ small16/ small18/ small20/   全字符集（数字/大写/小写/: . - / % [ ] ( ) ' # > < $ ~ _）
│  ├─ cjk/                     中文剪字 26px & 22px，共 42 张（老王晚上点地方到了给你留位…）
```

`layout.json` 的 `elements[]` 每条含 `name / kind / x / y / anchor / font / size / advance / color / sample / role`，
`role` 直接对应手环数据源（`battery / heart_rate / steps / calories / weather / second / event_log / bt_link`）。

## 3. 三条落地路径（按改动自由度排序）

### 路径 A：第三方工具编译（推荐，元素可绑数据源、可动）

1. 装 **easyface** / **Mi-Create** / 表盘自定义工具（bandbbs 上的 9 代版本）。编译目标必须选 **Band 9**，
   手环 9 的表盘包结构与 7/8 不同，用错目标编出来的包会装不上。
2. 新建工程，画布 **192×490**，背景层导入 `out/assets/base.png`。
3. 加图层，按下表摆（坐标直接抄 `layout.json`）：

   | 图层 | 素材 | x | y(基线) | 数据源 |
   |---|---|---|---|---|
   | 时间（4 位） | `assets/big/{0..9}.png` | 16 | 100 | 时 / 分，步进 32 |
   | 冒号 | `assets/big/colon.png` | 144 | 100 | 静态（或与秒同步闪） |
   | 日期 | `assets/small20/` | 10 | 124 | 星期+日+月+年，≤12 字符 |
   | 秒 | `assets/small16/` | 182(右对齐) | 45 | 秒 |
   | 电量% | `assets/small18/` | 182(右对齐) | 20 | 电量 |
   | 电量条 | 画 4 段矩形 或 `icons/bat_0..4` | 121 | 8 | 电量分档 |
   | 步数 | `assets/small18/` | 182(右对齐) | 232 | 步数 |
   | 心率 | `assets/small18/` | 182(右对齐) | 207 | 心率 |
   | 卡路里 | `assets/small18/` | 182(右对齐) | 257 | 卡路里 |
   | 温度 | `assets/small18/` | 182(右对齐) | 282 | 天气温度 |
   | 指标条 x5 | 矩形组 5 组 | 81 | 170/195/220/245/270 | 对应上表比例 |
   | 光标 | 矩形 9×14 | 154 | 436 | 每秒闪（或常亮） |

   > 上表 `y` 是 `layout.json` 的**基线**值；编辑器多用左上角坐标，取基线 y − 字号 约等于顶边：
   > 18px 字 → y−17，53px 大号 → y−53，20px → y−19。

4. 绑完预览一遍，特别检查：`HH:MM` 是否左对齐在 x=16、右侧数字列是否都贴 182 右对齐。
5. 编译 → 得到 `.bin` → 传到手环（小米运动健康"表盘"页 → 更多 → 自定义/导入，或工具自带推送）。
6. 装上前先在手机上留一份原厂表盘，随时能切回。

### 路径 B：相册表盘（零工具，10 分钟）

官方"相册表盘"只能放整张图 + 系统自己叠时间/日期，所以要用**不带大号时间**的版本：

1. 手机相册放 `out/preview_album.png`（或 `assets/base.png`，它把动态值全留空）。
2. 小米运动健康 → 设备 → 表盘市场 → 我的 → 相册表盘 → 选图。
3. 裁剪框里保持 **192:490 比例**，别裁掉四周 10px 边。
4. 系统时间会落在留白的中上部。若位置偏高/偏低，回到 `scripts/make_watchface.py`
   调 `Y_TIME` 与 `Y_DATE` 的留白区间后重跑脚本，再换图。
5. 相册表盘不绑步数/心率，`resmon` 那五行就只能当装饰——纯视觉党选这条最快。

### 路径 C：自己改设计后重新出图

```bash
pip install pillow
python scripts/make_watchface.py
```

脚本顶部集中了所有可调参数：

```python
P = 10                       # 安全边距
S18, A18 = 18, 11            # 正文字号 / 步进
S16, A16 = 16, 10            # 日志字号 / 步进
BIG, BIG_A = 53, 32          # 大号时间字号 / 步进
Y_STAT, Y_CMD, Y_TIME, ...   # 全部行坐标
BG, G0, G1, G2, G3, CY, AM, RED   # 调色板
```

* 想把终端配色换成**琥珀单色**（老 VT100 味）：`G1=(255,176,0)`、`G2=(190,120,0)`、`G3=(80,50,0)`、`G0=(255,232,180)`。
* 想换 **Solarized / Nord**：直接改 5 个常量即可，脚本里所有元素都引用它们。
* 想加一行日志或改文案：改 `state_idle()/state_lowbat()/...` 里的 `log=[...]`，长度 ≤17 字符（16px 字宽 10px）。
* 想换机型（手环 8 / 8 Pro）：改 `W, H` 与栅格常量，其余自动重排。

## 4. 很容易踩的坑

1. **字符溢出**：18px 等宽每字符 11px，192 宽减两侧 10px = 172px → 18px 字号最多 15 字符；
   16px 字号最多 17 字符。写文案先数格，别指望自动换行。
2. **大号时间别用比例字体**：冒号在等宽字体里只占 1 格，居中算法才成立（5×32=160）。
3. **右对齐列**：所有数值都用右对齐（`anchor="rs"`），位数变化时左侧自动伸缩，不会挤歪面板。
4. **圆角被裁**：胶囊屏四角是弧，坐标 <10 或 >182 的内容会被物理切掉。
5. **别把秒接到多个元素**：手环刷新率有限，多处每秒变化会掉帧且耗电。
6. **手环 9 表盘包不通用**：网上 7/8 代的 `.bin` 不能直装；只认 9 代目标编译的包。
